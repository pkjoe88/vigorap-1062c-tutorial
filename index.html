1 實體連接

  1. 將 VigorAP 1062C 的 LAN / PoE 埠用網路線接至 Vigor 2135 的 LAN 口或其下層 Switch
  2. 若使用 PoE 供電：確保 Switch 或 Vigor 2135 提供 PoE+ (802.3at) 電源
  3. 若使用變壓器供電：另接 DC 電源變壓器
  4. 確認 VigorAP 1062C 能從 Vigor 2135 取得 IP 位址（同一區域網路）
💡 LED 確認：VigorAP 1062C 正常運作時 LED 為綠燈慢閃；若為紅燈閃爍代表系統錯誤。
硬體連接示意
VigorAP 1062C 背面連接埠
LAN / PoE 埠 (2.5GbE) → 網路線 → Vigor 2135 LAN 口（或 PoE Switch）
DC 電源孔 → 變壓器（若不使用 PoE 供電）
Reset 按鈕 戳 5 秒恢復原廠設定

2 確認 Vigor 2135 的 APM 功能已開啟

  1. 開啟瀏覽器，登入 Vigor 2135 網頁管理介面（預設 http://192.168.1.1）
  2. 前往路徑：System Maintenance → Management
  3. 確認已勾選 Enable AP Management（啟用 AP 管理）
  4. 點選 OK / Apply 儲存
http://192.168.1.1 → System Maintenance → Management
系統維護 → 管理
Enable AP Management ✓ 已啟用（勾選）
Enable SNMP   未勾選（選用）
OK / Apply

3 授權 VigorAP 1062C

  1. 在 Vigor 2135 介面前往：Central Management → AP → Status
  2. Vigor 2135 會自動搜尋區網內的 VigorAP
  3. 觀察 AP 狀態：
    • 綠色（正常/已授權）：路由器已成功連線並取得管理權限 ✅
    • 紅色 + [Warn: Unauthorized]：未授權，需手動授權 ⚠️
  4. 若出現未授權：點選該 AP 清單中的 Password 按鈕，輸入 AP 目前的管理者帳密（預設 admin / admin）完成授權
  5. 狀態轉為綠色即代表管理權限取得成功
⚠️ 授權失敗排錯：若 AP 沒出現在清單中，請確認：(1) AP 是否已取得 IP、(2) 是否被 Mesh Slave 模式佔用、(3) 韌體版本是否過舊。

5 套用設定檔到 VigorAP 1062C

  1. 前往：Central Management → AP → Device
  2. 找到 VigorAP 1062C 裝置
  3. 勾選 Use AP Profile，下拉選擇剛建立的設定檔（如 Office_Wi-Fi）
  4. 點選 Save / Apply
  5. Vigor 2135 會自動將無線設定派發並寫入 VigorAP 1062C

6 後續管理與維護

集中維護功能

設定完成後，日後所有維護操作皆可在 Vigor 2135 的 Central Management → AP 直接執行，不需額外登入 AP 介面：

  • 🔄 重新開機 AP
  • 💾 備份 / 還原設定
  • ⬆️ 升級韌體
  • 📊 查看 AP 狀態與連線用戶

IP 固定建議

建議在 Vigor 2135 的 LAN → Bind IP to MAC 綁定 VigorAP 1062C 的 MAC 與 IP，方便日後管理。

問題可能原因與解決
AP 沒出現在 Status 清單 確認 AP 已取得 IP；確認未被 Mesh Slave 模式佔用；更新韌體

7 後續加裝第二台 VigorAP 1062C

💡 Vigor 2135 已啟用 APM，加裝第二台 1062C 流程更簡單 — APM 設定已就緒，直接授權 + 套用既有設定檔即可。

步驟 1：實體連接

  1. 將第二台 VigorAP 1062C 的 LAN/PoE 埠接至 Vigor 2135 的 LAN 口或同一個 Switch
  2. 確認 PoE 供電或接上變壓器
  3. 等待 LED 轉為綠燈慢閃（正常運作）

步驟 2：授權新 AP

  1. 登入 Vigor 2135 → Central Management → AP → Status
  2. 新 AP 會自動出現在清單中（IP 由 DHCP 自動分配，如 192.168.1.3）
  3. 若出現 [Warn: Unauthorized] → 點 Password → 輸入 admin / admin 完成授權
  4. 狀態轉綠色 ✅
http://192.168.1.1 → Central Management → AP → Status
AP 狀態清單（兩台 AP）
AP 名稱 MAC 位址 IP 位址 狀態
VigorAP 1062C #1 00:11:22:33:44:55 192.168.1.2 ● 已授權
VigorAP 1062C #2 00:11:22:33:44:66 192.168.1.3 ● 已授權

步驟 3：套用設定檔

  1. 前往 Central Management → AP → Device
  2. 找到第二台 VigorAP 1062C
  3. 勾選 Use AP Profile → 下拉選擇與第一台相同的設定檔（如 Office_Wi-Fi）
  4. 點 Save / Apply
✅ 完成！ 兩台 AP 都會廣播相同的 SSID，裝置可自動在兩台之間漫遊。

多台 AP 注意事項

項目說明
頻道規劃2.4GHz 建議用 1、6、11 不重疊頻道；5GHz 頻道較多可依環境選擇
傳輸功率AP 密集部署時可降低功率避免訊號重疊
Mesh 模式AP 之間無法用網路線連接時，改用 Role Setup → Slave Mesh 無線串聯
IP 固定在 Vigor 2135 的 LAN → Bind IP to MAC 為每台 AP 綁定固定 IP
VLAN 隔離可在 WLAN Profile 中對應不同 VLAN（如來賓網路）
管理上限Vigor 2135 最多可管理 50 台 VigorAP
