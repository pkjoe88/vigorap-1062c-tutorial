# Vigor 2135 + VigorAP 1062C 整合設定教學

DrayTek 居易科技 Vigor 2135 路由器搭配 VigorAP 1062C 無線基地台的完整設定指南。

## 📡 網路架構

```
Vigor 2135（路由器 + APM 主控，無無線功能）
  └── VigorAP 1062C（吸頂式 AP，提供 Wi-Fi 6）
        └── 無線終端裝置（手機、筆電、平板等）
```

## 📋 教學內容

1. **實體連接** — PoE/變壓器供電、網路線連接
2. **APM 功能啟用** — Vigor 2135 中央 AP 管理設定
3. **AP 授權** — VigorAP 1062C 授權流程
4. **WLAN 設定檔建立** — SSID、密碼、安全性、VLAN 設定
5. **設定檔套用** — 將設定派發至 AP
6. **後續管理** — 集中維護、韌體更新、IP 固定
7. **加裝第二台 AP** — 多台 AP 部署與漫遊設定
